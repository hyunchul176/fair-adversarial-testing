# Version map

This document holds the version map (former Section S7, Table S10). Its text comes verbatim from the supplementary material of the paper "Fair adversarial testing of automated vehicles in highway cut-ins: reference-shielded attacks and a capability-controlled evaluation", which is kept in this repository instead of being published with the paper (supplement draft v13 of 2026-10-12, text as of 2026-11-14). Section, figure and table numbers without "S" refer to the paper; numbers with "S" refer to sections and tables of these documents, and README.md lists where each is. The figures of the supplementary material are not reproduced.

Table S10 maps the versions of the agent to the results in which they appear. Policy-stage results are identical for v2j, v2s and v2s-S except where the severity floor changes what counts as a success. B58 and B60 (policy stage only) and B62 are version-independent, and B56, B59 and B61 report both refinements.
